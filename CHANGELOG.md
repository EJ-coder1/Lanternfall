# Changelog

## 0.1.0 (vertical slice)

- Project: Godot 4.4, GDScript, Compatibility renderer, landscape.
- Main menu: Continue, New Game, Settings, Credits, Exit.
- Player: run, variable jump, coyote time, jump buffer, sword (ground and air), Flare spell, damage, knockback, respawn.
- Enemy: Gloomback Crawler with patrol, chase, telegraphed lunge and recovery.
- World: Lanternroot Hollow with parallax, hidden Lumen platforms, 21 shards, 2 lantern posts, hint signs, Sun Sigil objective, one secret ledge.
- HUD, pause menu, multi-touch on-screen controls, gamepad and keyboard input.
- JSON save/load with atomic writes, settings file.
- Generated sound effects and music loop.
- Tests: 83 headless checks (`tests/run_tests.sh`).
- Fixed during development: menu root collapsing to zero size (anchors set in-tree).
